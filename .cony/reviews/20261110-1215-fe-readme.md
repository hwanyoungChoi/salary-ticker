## 이미지 속 금액과 손계산 (확인한 사실)
조건: 연봉 20,000,000, 기본 시간표(월~금 09:30~18:30), 2026-11-09(월) 14:00 Asia/Seoul.
- 분모 = 52 × 5 × 32,400 = 8,424,000초
- 경과 = 09:30 → 14:00 = 16,200초
- 오늘 번 돈 = 20,000,000 × 16,200 ÷ 8,424,000 = 38,461.54 → 버림 **38,461** (menubar.png에 `38,461`)
- 초당 = 20,000,000 ÷ 8,424,000 = 2.374 → **초당 2.4원** (panel.png)
- 일급 = 20,000,000 × 32,400 ÷ 8,424,000 = 76,923.08 → 76,923 (README 예시에만 사용)
- 테스트가 `earnedToday == 38_461`, `perSecondText == "초당 2.4원"`을 `#expect`로 확인한 뒤 렌더링한다. PNG를 Read로 열어 눈으로도 확인했다: 입력칸 `20,000,000`, `초당 2.4원`, 월~금 켜짐(파랑)·토일 꺼짐, 출근 오전 9:30, 퇴근 오후 6:30, 종료 버튼. 라이트 모드.

## 렌더링 방식과 이유
- 다시 만들기: `RENDER_SCREENSHOTS=1 swift test --filter ScreenshotTests` → `docs/panel.png`, `docs/menubar.png` 덮어씀.
- 평소 `swift test`에서는 스위트가 skipped로 나오고 파일을 쓰지 않는다(전후 md5 같음 확인).
- 저장소: `UserDefaults(suiteName: "SalaryTickerScreenshotTests.<UUID>")` 주입, 끝나면 `removePersistentDomain`. 표준 도메인·`defaults`는 읽거나 바꾸지 않았다. 시각은 `TickerModel(now:)` 고정, 틱 시작 안 함.
- `ImageRenderer`를 먼저 썼으나 macOS에서 TextField·DatePicker가 노란 금지 표시 자리표시자로 나왔다(확인함). 그래서 화면에 띄우지 않은(`orderFront` 안 함) borderless `NSWindow`에 `NSHostingView`를 넣고 `cacheDisplay(in:to:)`로 2배 비트맵에 그렸다. 화면 기록 권한이 필요 없다.
- 창이 key가 아니라 요일 토글이 비활성 회색으로 그려져, `.environment(\.controlActiveState, .key)`로 패널이 열린(활성) 상태 색에 맞췄다. 로캘 ko_KR, 시간대 Asia/Seoul, `NSAppearance(.aqua)`로 고정.
- 메뉴바 이미지는 라벨 View만 창 배경색 위에 그린 것이다. 메뉴바 모양을 흉내 낸 배경은 넣지 않았고, README 캡션에 "앱 화면을 렌더링한 이미지(예시 연봉 2천만 원, 월요일 14:00)… 실제 메뉴바를 캡처한 화면은 아닙니다"라고 적었다.

## 부수 효과 (추론 포함)
- 렌더링 중 `PanelView.onAppear`가 실행되어(입력칸이 채워진 것으로 확인) `NSApp.activate()`가 테스트 실행 프로세스에서 호출된다. 재생성할 때 잠깐 포커스가 테스트 프로세스로 갈 수 있다(추론, 화면으로 확인 못 함). 평소 `swift test`에서는 실행되지 않는다.
- suite 도메인 정리 뒤 `onDisappear`의 저장 시도 등으로 `~/Library/Preferences/SalaryTickerScreenshotTests.*.plist`가 남았다. 내가 만든 이 3개만 지웠다. 기존 다른 테스트들도 같은 방식으로 `SalaryTicker*Tests.*.plist`를 남기고 있다(188개, 이번 범위 밖, 손대지 않음).
- 앱 실행, 프로세스 조회·종료, 표준 UserDefaults 접근은 하지 않았다.

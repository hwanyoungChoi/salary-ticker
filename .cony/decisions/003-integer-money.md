# ADR-003 금액 연산: Int 원 단위, 연봉 상한
- 상태: 채택
- 맥락: 부동소수 연산은 딱 떨어져야 할 시각에 1원 모자라는 값(예: 99,999)을 낼 수 있다.
- 선택지: A. Double / B. Int 정수 연산 / C. Decimal
- 의견: pm(B 추천, 부동소수 오차 방지) / fe(조건부 찬성, 연봉×경과초가 Int64를 넘으면 크래시하므로 연봉 상한 필요) / qa(조건부 찬성, 같은 이유로 상한이나 오버플로 방어, 버림과 반올림을 구분하는 예시 추가)
- 검토 원문: [fe](../reviews/20261110-1121-fe-spec-salary-counter.md) · [qa](../reviews/20261110-1121-qa-spec-salary-counter.md)
- 결정: B. 연봉 상한을 둬서 오버플로가 일어나지 않게 한다. 상한 값은 제품 기본값 · 사용자 확인 전.
- 이유: 테스트로 정확한 값을 확인할 수 있고, Decimal보다 단순하다.
- 뒤집을 조건: 원 단위 아래(소수점) 표시가 필요해질 때.
